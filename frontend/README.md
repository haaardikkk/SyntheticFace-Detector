# Synthetic Face Detector: frontend

React 18, Vite, Tailwind CSS, Framer Motion, Recharts, Axios.

```bash
npm install
npm run dev      # http://localhost:3000, uses the backend at http://localhost:9000 (.env.development)
npm run build    # production build; uses VITE_API_URL, or the Hugging Face Space if it is not set
```

See the [main README](../README.md) for the API and [DEPLOYMENT.md](../DEPLOYMENT.md) for hosting.
