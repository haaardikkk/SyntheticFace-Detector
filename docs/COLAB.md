# Training the v3 model on Google Colab

Notebook: `notebooks/train_synthetic_face_colab.ipynb`, generated by `python notebooks/build_colab_notebook.py`.

**You do not download any dataset.** The notebook reads them directly from the Hugging Face Hub. No account or token is needed.

## Run it

1. https://colab.research.google.com → **File → Upload notebook** → pick `train_synthetic_face_colab.ipynb`.
2. *(Optional)* 🔑 **Secrets** → add `HF_TOKEN` (a free read token from huggingface.co/settings/tokens) with notebook access on.
   Downloads are faster and less often throttled.
3. *(Recommended)* A check first: in the first code cell set `QUICK_RUN = True`, then **Run all** on a GPU runtime. It ends with a
   score table for old and new model, in its own Drive folder `SyntheticFace_v3_quick`. Scores from it mean nothing: too little data.
4. Set `QUICK_RUN = False`. **Runtime → Change runtime type → CPU**, then **Run all**, and allow Drive access.
   Data preparation does not use a GPU, so it costs far fewer compute units. When it finishes, the notebook stops and says:
   *"Data is ready and saved in Drive"*.
5. **Runtime → Change runtime type → GPU** (a T4 is enough), then **Run all** again.
6. It finishes by printing the comparison table, saving `synthface_v3.zip` to Drive and releasing the GPU.

## If anything stops it

Tab closed, compute units ran out, runtime crashed, or you pressed Stop: **reconnect and Run all**. Nothing else is needed.

| What is interrupted | What is lost at most | How it continues |
|---|---|---|
| Data preparation | ~10 minutes | `data/<source>/progress.json` records the exact position in every dataset |
| Training | ~30 minutes (`SAVE_MINUTES`) | `checkpoints/last.pt` has the model, optimizer, schedule and step |
| Pressing Stop, or the time budget ending | nothing | A checkpoint is saved before stopping |
| Final scoring | the scoring only | Training is marked finished, so scoring simply reruns |

**Out of units and no more coming?** Set `FORCE_FINISH = True` in the first cell. It skips the remaining training, then scores and
packages the best model so far. This also works on a CPU runtime, only more slowly.

## What is in `MyDrive/SyntheticFace_v3/`

| Path | What | Size |
|---|---|---|
| `data/<source>/part-*.tar` + `.idx.json` | prepared face crops, one folder per source | ~7 GB in total |
| `checkpoints/last.pt` | full training state | ~350 MB |
| `best_model.pth` | best model so far | ~115 MB |
| `synthface_v3.zip` | **final, backend-ready model** | ~60 MB |
| `metrics.json`, `history.json` | all final scores; validation over time | small |
| `sample_maps.png` | predictions and alteration maps to look at | small |
| `run_log.txt` | everything that happened, across sessions | small |

**Google Drive space:** you need about 10 GB free, and files overwritten by the notebook move to Drive's **Trash**, which still counts.
On the free 15 GB plan, empty the Trash now and then during training, or reduce `DATA_SCALE` (0.6 needs about 4 GB for the data).

To start over, delete the `SyntheticFace_v3` folder. To keep the data and retrain, delete only `checkpoints/`, `best_model.pth`,
`model_choice.json` and `training_finished.json`.

## Datasets

| Dataset | Used for | Images used |
|---|---|---|
| [OpenRL/DeepFakeFace](https://huggingface.co/datasets/OpenRL/DeepFakeFace) | IMDB-WIKI real, SD inpainting, InsightFace swaps, SD 1.5 | up to 28k identities, about 90k |
| [bitmind/SyntheticFacesHighQuality-T2I](https://huggingface.co/datasets/bitmind/SyntheticFacesHighQuality-T2I) | Flux.1 pro/dev/schnell, SDXL, DALL-E 3 | ~30k |
| [ComplexDataLab/OpenFake](https://huggingface.co/datasets/ComplexDataLab/OpenFake) `core/train` | modern generators; only images with a face | up to 30k fake, 15k real |
| [TheKernel01/140k-Real-and-Fake-Faces](https://huggingface.co/datasets/TheKernel01/140k-Real-and-Fake-Faces) | FFHQ real, StyleGAN | 25k + 15k |
| [bitmind/celeb-a-hq](https://huggingface.co/datasets/bitmind/celeb-a-hq) | high-quality real faces | 15k |
| [xingjunm/WildDeepfake](https://huggingface.co/datasets/xingjunm/WildDeepfake) `train` | compressed video frames, real and swapped | up to 15k + 15k |
| OpenFake `core/test` | **gold**: generators not in training | 5k fake |
| OpenFake `reddit` | **gold**: images as they circulate online | up to 3k + 3k |
| WildDeepfake `test` | **gold**: videos not in training | 4k + 4k |

`CelebDF`, which the old model trained on, is not on this list: it is video, and its access is by request.
Most of these datasets allow **research and non-commercial use only** (FFHQ, CelebA-HQ, OpenFake CC-BY-NC). That fits this project.
Selling the model or the service would need a different training set.

*Not used, but worth a look:* [Deepfake-Eval-2024](https://huggingface.co/datasets/nuriachandra/Deepfake-Eval-2024) is a strong
real-world test set. Access must be requested by hand.

## Reading the results

The final cell prints, for the **old and the new model on the same images**:

| Number | Meaning |
|---|---|
| `auc` | How well real and fake are ranked, independent of any threshold. 0.5 = chance, 1 = perfect |
| `balanced_acc` | Average of the share of fakes caught and the share of real faces accepted. Unlike plain accuracy, it cannot be inflated by class imbalance |
| `fake_recall` | Share of fakes caught |
| `real_specificity` | Share of real faces correctly accepted |
| `eer` | Error rate where false alarms and misses are equal. Lower is better |
| `auc_jpeg50`, `auc_half`, `auc_jpeg50+half` | The same AUC after heavy compression, half resolution, and both |
| `mask_iou` | Overlap of the alteration map with the true altered region. 1 = perfect |

**Quote the GOLD numbers.** The "held-out test" comes from the same generators as training, so it is easier. Lower gold scores are normal:
detecting generators a model has never seen is the hard open problem of this field.

The old model's scores carry one caveat: it now receives the new face crops rather than its original OpenCV Haar crops. That is
also how the rebuilt backend serves it.

## Settings (first code cell)

| Setting | Default | Meaning |
|---|---|---|
| `QUICK_RUN` | False | True = short end-to-end check on small slices |
| `DATA_SCALE` | 1.0 | Scales every image cap; 0.6 uses less Drive space and trains faster |
| `CAPS` | see cell | Images kept per source |
| `BATCH_SIZE` | 64 | Doubled automatically on GPUs with ≥ 22 GB. Lower it on CUDA out of memory (before the first checkpoint) |
| `EPOCHS` | 10 | Passes over the training images. Early stopping may end sooner |
| `SAVE_MINUTES` | 30 | Minutes between training checkpoints. Lower is safer but fills the Trash faster |
| `MAX_TRAIN_HOURS` | 7.5 | Training per session, then it pauses safely |
| `FORCE_FINISH` | False | Score and package the best model so far |
